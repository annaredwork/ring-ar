# Ring AR — демо примерки колец

Простая одностраничная AR-примерочная: камера + отслеживание руки (MediaPipe Hands) +
кольцо, наложенное на средний палец в реальном времени. Работает полностью в браузере,
без сборки и бэкенда.

## Как запустить

Камера в браузере требует безопасный контекст (https:// или localhost) — открыть
`index.html` двойным кликом (`file://`) может не сработать. Проще всего поднять
локальный сервер в этой папке:

```bash
# любой из вариантов
python3 -m http.server 8080
# или
npx serve .
```

Затем открыть `http://localhost:8080` в браузере (лучше всего в Chrome на телефоне
или ноутбуке с камерой) и разрешить доступ к камере.

## Как это устроено

- **Отслеживание руки** — MediaPipe Hands (загружается с CDN), 21 точка на кисти.
  Кольцо крепится к точкам 9 (основание среднего пальца) и 10 (следующий сустав),
  поворачивается и масштабируется вместе с пальцем.
- **Изображение кольца** — `assets/ring1_band.png`, вырезано из присланного рендера
  кольца (вид спереди/сбоку, как оно выглядит надетым) с прозрачным фоном.
  `assets/ring1_circle.png` используется как иконка в карусели выбора.
- **Интерфейс** — полноэкранная зеркальная камера, карусель колец снизу, кнопка
  спуска затвора для сохранения кадра — в духе Instagram/Snapchat-фильтров.

## Как добавить ещё кольца

1. Обработать новые фото так же, как исходные (обрезать, убрать белый фон в PNG
   с альфа-каналом). Скрипт для этого — не входит в поставку, но логика простая:
   помечать прозрачными пиксели близкие к белому и обрезать по границам содержимого.
2. Добавить файлы в `assets/`.
3. Добавить новый объект в массив `RINGS` в `index.html` (внизу файла, в `<script>`):

```js
{
  id: "ring2",
  name: "Название",
  band: "assets/ring2_band.png",
  circle: "assets/ring2_circle.png",
  aspect: null,
  widthFactor: 1.85,   // подобрать под конкретное кольцо
  vOffset: 0.08
}
```

`widthFactor` и `vOffset` может понадобиться подстроить под конкретную форму
кольца методом проб (по умолчанию подобрано под присланный рендер).

## Ограничения текущей версии

- Это не полноценная 3D-фотограмметрия — кольцо рисуется как 2D-спрайт,
  выровненный по направлению и толщине пальца (так же устроены реальные
  AR-фильтры украшений в Instagram/Snapchat). Для настоящего вращаемого 3D
  потребуется гораздо больше исходных фото или 3D-модель кольца из CAD/рендер-движка.
- Отслеживается один жест — открытая ладонь в кадре, кольцо садится на средний
  палец обеих обнаруженных рук (`maxNumHands: 2` в `index.html`).
